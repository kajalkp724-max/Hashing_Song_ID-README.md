# Hashing of Song IDs

## Assignment 7

Implementation of a hash table using the Division Method for storing song IDs.

### Song IDs

105, 210, 315, 420, 525, 630, 735, 840

## Objectives

- Implement a hash table using the Division Method.
- Insert the given song IDs.
- Identify collisions.
- Perform searching using hashing.
- Perform linear search.
- Count comparisons/operations.
- Calculate the load factor.
- Compare hashing and linear search.
- Analyze the suitability of hashing for the application.
